# 博客工作台

在这里记录、画图、整理，再把准备好的文章发布到博客。

```mizuki-workbench
```

## 常用目录

- 工科基本功 · 一生一芯 · EDA · STM32 · Matlab
- 杂谈 · 有趣的东西 · 日记
- 附件 · 绘图

左侧文件列表就是博客的 **posts**，可以直接新建分类、移动或重命名笔记。

## 写作与发布

1. 点击 **新建笔记 / 文章**，选择标题、分类和类型。
2. 写 Markdown、LaTeX、双向链接，或插入电路图和手绘。
3. 准备公开时打开笔记，按 **Ctrl+Shift+P** 切换公开。
4. **启动预览 → 打开预览**，检查文章。
5. **停止预览 → 发布博客**，执行原来的 pnpm deploy。

新笔记默认不公开，未公开内容可以进入 Git，但不进入博客。
