# StupiD IDEA

~~经常编程的人都知道~~我们在敲代码的时候非常容易手滑，或者卡切换输入法，导致以下代码发生
```c
井include<stdio。h》
int mian()
{
    print(“Hello World！”)
    retrun 0;
}
```
当我们把代码交给不那么现代的编译器后，编译器就会看不懂，然后拒绝编译并报错，非常地不人性。

现在这个项目解决了这一苦恼，不论是`井include<stdio。h》`,还是`cout ??= fmt.Println<echo~("HELLO")>::await!; return WORLD;`这个IDE都能编译并运行。
