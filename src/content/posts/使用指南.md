## 公开规则

publish: false 不发布；publish: true 且 draft 不为 true 才发布。旧文章没有 publish 时，保留原来行为。没有标题和日期的临时文件不进入博客。未公开不等于 Git 私有。

工作台的发布按钮执行 pnpm run deploy：构建、git add -A、提交、推送。因此仓库内其他改动也会随原有部署流程提交。不要在预览运行时构建，先停止预览。

## 双向链接和嵌入

`[[分类/笔记|显示名称]]`、`[[笔记#标题]]`、`[[笔记#^块ID]]` 可发布为网页链接。同名笔记请写完整分类路径。

`![[公开笔记#标题]]` 可嵌入正文；公开笔记嵌入未公开笔记会阻止构建。引用未公开笔记只显示文字。

图片：`![[附件/图.svg|600]]`。Excalidraw 保存时导出 SVG；在博客中显示导出图，不运行绘图编辑器。Drawio 建议使用 .drawio.svg。

## 模板与随手记

“模板”文件夹包含课程、实验、日记和普通笔记。工作台新建按钮也可以直接选择笔记类型；日记使用左侧日历按钮。QuickAdd 的“随手记到收件箱”将碎片想法追加到收件箱。

## 公式与绘图

LaTeX Complete：在公式内输入 `\fra` / `\alp` 会弹出命令候选，方向键选择、Tab 或 Enter 确认。LaTeX Suite 的 `//`、`sq` 分别快速展开分数和根号模板。


公式用 $…$ 或 $$…$$，LaTeX Suite 提供快速输入。建议在数学模式内使用微电子快捷片段 gm、vgs、vds、vth、ids、cgs、cgd、ro。

Excalidraw 用于能带图、器件截面和推导手绘，绘图默认放在“绘图”。Drawio 用于规范电路和框图。两边都支持 Mermaid 和 markmap 代码块。Canvas 适合整理笔记，发布时请导出图片。

粘贴或拖入图片时，文件自动放到当前笔记所在目录的 `images` 子文件夹，没有文件夹则创建。例如 `微电子笔记/MOS.md` 的图片在 `微电子笔记/images/`。

## Pi

Pi Agent 沿用本机 Pi 的模型配置。默认 Edit 模式，可以读取、撰写和修改笔记；不开放终端命令。需要仅检查时切换为 Read-only。模式控制不是操作系统沙箱。笔记内容会发送给现有模型提供方。AI 不应自动发布、推送或删除你的笔记。
