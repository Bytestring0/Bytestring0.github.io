# 博客迁移

虽然`ShokaX`非常简约好看，但还是太小众了，找不到有关Latex的帮助，渲染问题得不到解决，于是花了一天的时间找到了一款新的主题`Mizuki`并迁移过来，虽然遇到了很多麻烦。  

# 安装Mizuki

## 环境搭建

经典的安装[NodeJS](https://nodejs.org/) 

然后安装`pnpm`这个包管理工具，据说和`npm`相比能减少`node_modules`的体积  

![v2-e754eaafe8330ad33c19afb707e8da4f_r.png](https://youke1.picui.cn/s1/2025/11/13/6915a15617baa.png)
!!但我还是觉得很大（!!  

```bash
npm install -g pnpm
```


使用[Git](https://git-scm.com/)下载

## 启动项目

首先将`Mizuki`项目克隆到本地

```bash
git clone https://github.com/matsuzaka-yuki/mizuki.git
cd Mizuki
```

然后安装依赖

```bash
pnpm install
```

在`src/config.ts`中配置完相关信息后就可以运行开发环境了

```bash
pnpm dev
```

这时打开本地的链接就可以看到项目了。

## 部署到Github Page

1. 注册名为`username.github.io`的仓库
2. 使用Git连接远程仓库（在此之前可以先将原来的.git文件夹删了）
```bash
git init
git remote add origin https://github.com/username/username.github.io.git
```
3. 配置Action

`Mizuki`主题非常贴心地配了一个`Github Action`可以自动化部署页面到`Pages`分支，不过新版的`.github/workflows/deploy.yml`好像已经存在了（？），那么就可以跳过这一步了。

4. 先进行一次推送
```bash
pnpm build
git add .
git commit -m "init"
git push -u origin main
```

5. 在Github中将`Settings->Pages`的源设置为Pages分支

这样就可以自动化部署了，每次使用`Git`推送时会自动将`dist`这个目标产物文件夹推送到Pages分支，这样就可以打开对应网址看到自己的网页了。

6. 配置自定义域名

关于域名配置可以看这篇文章[GithubPages+自定义域名+Cloudfare加速+浏览器收录（2025最新排坑）](https://blog.csdn.net/m0_74766888/article/details/146487753)

在`public`文件夹中添加一个名为`CNAME`的文件，里面填上自定义域名。
```
example.com
```
把`astro.config.mjs`中关于站点设置的部分改成这样
```js
export default defineConfig({
	site: "https://example.com",

	base: "",
```
然后就OK啦！
