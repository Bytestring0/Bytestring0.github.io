SSD1619A墨水屏驱动
2026-05-09
未分类
无标签
统计加载中...

最近想做一个墨水屏的小项目玩玩，就去淘了一个4.2寸的墨水屏，看标签是大连佳显的屏，去官网找到了驱动IC是SSD1619A，正好写一个底层驱动。

阅读数据手册#

数据手册可以从6 Functional Block开始看

引脚定义#

主要有BUSY，RES#，CS#，D/C#，SCL，SDA需要配置。

数据通信#

本次使用的是4线SPI，阅读时序图，该芯片使用SPI模式0进行通信，高位在前，DC脚为低电平写入命令，高电平写入数据。

RAM#

RAM是用来写入显示数据的，SSD1619A有两块RAM，一块用于显示黑白，一块用于显示红色，尺寸都是 400x300 bits。数据写入是用byte写入的，所以一块RAM需要写400x300/8=15000个字节，从DB0一直到DB14999。对于同一个像素位置，需要分别设置R和B/W这两个bit，从而决定是什么颜色。 这里提到了三个命令

  • Data Entry Mode Setting：控制XY方向上是否递增
  • Driver Output Control： 选择扫描方式
  • Gate Scan Start Position ： 设置扫描起点

命令#

命令比较重要，用来向IC发送数据，决定工作方式，显示图形等等，现在依次介绍。

Driver Output control#

命令： 0x01 数据：

  • A[8:0]：设置MUX Gate，也就是多少行，墨水屏是300x400的，所以固定0x12B=299。因为一次只能发送一字节，所以A[8]需要发完低七位后再发一次。
  • SM/GD（可以看一下图8-1）：
    • 00：顺序对应每一行
    • 01：交换上下两行交错对应
    • 10：偶数从0开始，奇数从150行开始
    • 11：偶数从150行开始，奇数从0开始
  • TB：
    • 0：从上到下扫描
    • 1：从下到上扫描

没啥用，默认就行。

Gate Scan Start Position#

命令： 0x0F 数据：

  • SCN[8:0]：Gate的起始位置，配合上面的A[8:0]可以将图形截出一个区域，剩下的区域不用。

感觉也没啥用（

Data Entry Mode Setting#

命令：0x11 数据：

  • AM：
    • 0：地址沿X方向更新
    • 1：地址沿Y方向更新
  • ID[1:0]：决定XY递增还是递减

一般都是00

Set RAM X#

命令：0x44 数据：

  • XSA[5:0]:起始位置（X因为是400/8=50所以6位就够了，后面Y是300所以需要9位）
  • XEA[5:0]:终点位置

决定写RAM的哪一块区域（X）

Set RAM Y#

命令：0x45 数据：

  • YSA[8:0]:起始位置
  • YEA[8:0]:终点位置

决定写RAM的哪一块区域（Y）

Set RAM Address Counter#

命令：0x4E和0x4F 数据：

  • XAD[5:0]：X写指针
  • YAD[8:5]：Y写指针
